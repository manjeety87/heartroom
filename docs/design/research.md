## Patterns from skribbl, Gartic, Jackbox, Board Game Arena, lichess, Ludo King, Plato

1. Link first, no account: the link opens a nickname prompt, then the room.
2. The code is a secret: lock room, short-lived codes.
3. Host-tunable settings per room (rounds, timers, custom word lists).
4. Rejoin with the same name and code keeps the seat.
5. The audience is a real role (reactions / predictions), not a leftover.
6. One-tap rematch in the same room, with the first player rotating.
7. Quitting costs something (BGA: the quitter counts as last place plus a penalty; games abandoned early don't count).
8. Rating credibility: lichess needs 30 rated games plus recent activity before showing a player on leaderboards.
9. Separate competitive and casual modes.
10. Kick, and vote-kick when the host is away. Emoji reactions instead of text chat.

**Anti-patterns players complain about:** "rigged" randomness (Ludo King dice), ads in the middle of a game, no
penalty for leaving (Plato), stranger abuse, accounts lost in a migration, penalties for things the player could not avoid.

## Word Guess

* **Two lists:** secret words come from a curated *common* list, and guesses come from a larger *valid*
  list. ENABLE is public domain (use it for valid guesses). SCOWL size ≤50 has a clean licence and needs
  its notice included (use it for common words).
* **Repeated letters (two-pass):** first mark the exact matches, then mark "wrong place" from left to
  right, never more often than the secret still has that letter left. Extra copies are absent. Tests:
  APPLE/PAPAL, SPEED/ABIDE, EVADE/CEASE.
* **2-player fairness (Jotto style):** both players set a word and both guess. Fewer guesses wins, and
  ties go to time or a draw. One-sided rounds are a casual mode only. 3+ players = one setter, the
  others race (v1.1), and the racers' guesses stay hidden from each other.
* **Hinglish:** romanised spelling varies (main/mai/mein), so position feedback breaks. English only in
  v1. Later, a hand-picked Hinglish pack with one fixed spelling per word.
